# 사다리 계산

한 번의 주문을 가격 구간에 나눠 거는 규칙입니다. 계산은 `internal/ladder`에 있고 거래소나 데이터베이스에 의존하지 않는 순수 함수입니다.

## 입력

| 항목 | 내용 |
|---|---|
| 시장 | 토스증권 · 업비트 KRW · 업비트 USDT |
| 종목 | 보유 목록에서 선택하거나 직접 입력 |
| 방향 | 매수 · 매도 |
| 기준가 | 현재가 · 평균 매수가 · 직접 입력 |
| 시작 오프셋 | 기준가에서 얼마나 떨어진 곳부터 시작할지 |
| 종료 오프셋 | 어디까지 펼칠지 (시작보다 멀어야 함) |
| 분할 수 | 3 · 5 · 10 · 15 · 20 |
| 총량 | 매도는 수량, 매수는 금액 |

매도는 기준가 위로, 매수는 기준가 아래로 펼칩니다.

## 가격

```
start = 기준가 × (1 ± 시작 오프셋)
end   = 기준가 × (1 ± 종료 오프셋)
p(i)  = start × (end / start)^(i / (n−1))          i = 0 … n−1
```

등비로 배치하는 이유는 가격을 퍼센트로 인식하기 때문입니다. 단계마다 수익률 간격이 일정해지고, 구간이 넓을수록 기준가에 가까운 쪽이 촘촘해져 체결 확률이 높은 구간에 주문이 더 많이 놓입니다.

지수 계산만 부동소수점을 쓰고 결과는 곧바로 호가 단위로 스냅합니다. 금액과 수량 계산에는 부동소수점을 쓰지 않습니다.

**호가 반올림은 유리한 방향으로 고정**합니다.

| 방향 | 반올림 | 이유 |
|---|---|---|
| 매도 | 올림 | 한 틱이라도 비싸게 |
| 매수 | 내림 | 한 틱이라도 싸게 |

반올림한 뒤 같은 가격이 된 단계는 하나로 병합합니다. 미리보기에 `10분할 요청 → 7개 주문 (호가 중복 3건 병합)`처럼 표시합니다.

## 수량

- **매도 — 균등 수량.** 보유 수량을 단계 수로 나누고 시장의 수량 단위로 내림합니다. 토스는 정수 주수, 업비트는 소수점 8자리입니다.
- **매수 — 균등 금액.** 예산을 단계 수로 나누고 각 단계의 가격으로 살 수 있는 수량을 구합니다. 낮은 가격 단계에서 더 많이 사게 되어 평균 단가가 내려갑니다.

나누어떨어지지 않는 나머지는 **기준가에 가장 가까운 1단계**에 싣습니다. 체결 확률이 가장 높은 단계에 잔여를 실어 미체결로 남는 양을 줄입니다.

매수는 어떤 경우에도 예산을 넘지 않습니다. 나눗셈이 항상 내림이기 때문입니다.

## 최소 주문

| 시장 | 최소 |
|---|---|
| 업비트 KRW | 5,000원 |
| 업비트 USDT | 0.5 USDT |
| 토스증권 | 1주 (정수 수량만) |

모든 단계가 이 조건을 통과해야 주문을 만듭니다. 통과하지 못하면 가능한 최대 분할 수를 계산해 그 값으로 바꾸는 버튼을 제시합니다.

## 예시

**매도** — 업비트 KRW-SOL, 기준가 200,000, +2.5% ~ +10%, 10분할, 보유 20

```
  #        가격      수량        금액
  1     205,000         2     410,000
  2     206,700         2     413,400
  3     208,300         2     416,600
  4     209,900         2     419,800
  5     211,600         2     423,200
  6     213,300         2     426,600
  7     214,900         2     429,800
  8     216,600         2     433,200
  9     218,300         2     436,600
 10     220,000         2     440,000

총 수량 20 · 총액 4,249,200 · 평균가 212,460 (+6.23%)
```

**매수** — 업비트 KRW-SOL, 기준가 100,000, −2% ~ −10%, 5분할, 예산 1,000,000

```
  #        가격          수량        금액
  1      98,000    2.04081633     200,000
  2      95,900    2.08550573     200,000
  3      93,900    2.12992545     200,000
  4      91,900    2.17627856     200,000
  5      90,000    2.22222222     200,000

총 수량 10.65474829 · 총액 1,000,000 · 평균가 93,854.87
```

같은 예산을 수량 균등으로 나누면 평균 단가가 94,000 부근이 됩니다. 금액 균등이 더 낮은 단가를 만듭니다.
