# ETF 월간 교체 전략

토스의 비레버리지 ETF를 하나의 공동 예산으로 운용한다. `kind=rotation`, `symbol=ETF-ROTATION`, `rotation_policy=monthly_252_top2_v1`로 저장하며 기존 전략과 동일하게 **DRAFT 저장 → 설정 확인 → 별도 시작 승인**을 거친다. 전략 생성은 주문을 만들거나 자금을 배정하지 않는다. 과거 성과나 최적 수익을 보장하는 기능이 아니다.

## 고정 규칙

- 대상: SPY, QQQ, IWM, IEF, TLT, GLD, SHY.
- 신호: 최근 252거래일 배당 포함 수익률. 양수인 상위 2개에 각 50%를 배정한다. 양수 후보가 하나면 절반, 없으면 전부 USD 현금으로 둔다. 동률은 위 종목 순서로 결정한다.
- 최초 진입: 시작 직전 완성된 정규장 종가로 목표를 정한다. 과거 월초 가격에 체결된 것으로 처리하지 않는다.
- 이후 선정: 매월 첫 거래일 종가로 순위를 갱신하고 다음 정규장부터 집행한다. 월중 재시작하거나 데이터 제공자가 과거 값을 수정해도 이미 정한 월별 목표를 소급 변경하지 않는다.
- 비중 조절: 직전 종가와 실제 체결 장부로 일별 목표 수량을 계산한다. 목표와 실제 비중이 5%p 이상 벌어지면 조절하고, 탈락 종목은 청산한다. 장중 가격 움직임으로 목표 수량을 반복 변경하지 않는다.
- 수량: 정수 주식. 수수료와 잔여 현금을 고려하므로 실제 비중은 50%와 다를 수 있다.

상위 두 종목이 같은 자산군일 수 있다. 종목 분산이 항상 주식·금·채권의 동시 분산을 뜻하지 않는다.

## 데이터와 손익

공개 Yahoo Finance 일봉·배당으로 인과적인 총수익 지수를 계산한다. 수정 종가와 현금 배당을 이중 가산하지 않는다. XNYS 달력으로 휴장·조기 폐장·누락 거래일을 검사하며, 7개 종목의 최신 완성 거래일이 일치해야 판단한다. 일봉은 별도 비동기 작업으로 수집하므로 업비트 주문 대조를 다운로드 완료까지 기다리게 하지 않는다.

응답 오류, 통화·종목 불일치, 종가·거래량 누락, 일봉 부족, 기간 내 분할 이벤트가 있으면 주문 판단을 보류한다. 현재 분할 조정은 자동 승인하지 않는다. 오류가 난 ETF를 몰래 제외하거나 누락 가격을 보간하지 않는다. 원본 응답의 SHA-256과 수집 시각을 저장하고 주문 신호에 데이터 지문을 남긴다.

실행 가격은 토스의 최신 양방향 호가다. 공개 일봉 가격을 실시간 주문 가능 가격으로 취급하지 않는다. 종목·시세·수수료·현금·매도 가능 수량을 토스에서 점검한다.

**배당은 순위 계산에 포함하지만, 실제 입금된 배당금은 전략 현금에 자동 편입하지 않는다.** 전략의 운용 손익은 배당을 제외한 매매·평가 손익이다. 미확인 지급일·원천징수액을 추정해 가용 현금이나 수익으로 기록하지 않는다. 계좌 전체 현금 조회와 전략 장부는 구분한다.

## 주문과 장부

포트폴리오별 현금과 종목별 수량·취득 원가·실현 손익·비용을 관리한다. 부분 체결과 뒤늦은 수수료 정정을 기존 체결 원장으로 반영한다. 다른 ETF의 수량을 매도 가능 수량으로 합산하지 않는다.

한 번에 주문 하나만 준비하며 매도부터 처리한다. 미체결·미확인·취소 확인 중인 주문이 있으면 다음 주문을 만들지 않는다. 매도 요청만으로 현금이 생긴 것으로 계산하지 않고, 체결 장부와 실제 매수 가능금액을 확인한 뒤 매수한다.

미국 정규장에서 지정가 DAY 주문을 사용한다. 마감 65초 전부터 신규 제출을 중단하며 미체결은 기존 60초 취소 정책과 세션 종료 확인을 적용한다. 명확히 거절된 주문은 자동으로 다시 만들지 않고 전략을 중단한다. 취소 후 잔량 조절도 전략별 하루 최대 14회 주문 준비 안에서 수행한다. 미확인 토스 주문의 복구는 기존 멱등성 키와 유효시간을 유지하며 정규장 밖에서는 재제출하지 않는다.

기존 토스 손실 한도와 계좌 대조를 그대로 적용한다. 위험 중단은 미체결 취소·보유 유지이며, 손절매나 최대 손실 보장이 아니다. 투자 대상 7개 중 하나라도 다른 전략이 자금을 배정받고 있으면 중복 운용을 거절한다. 봇 외부의 기존 ETF 보유분도 자동 편입하지 않는다.

## 생성과 배포

웹의 새 전략에서 **ETF 월간 교체**를 선택하거나 기존 `/api/strategies`에 아래 설정을 전달한다. API의 시작 명령은 별도다.

```json
{
  "name": "ETF 월간 모멘텀 252 · 상위 2개",
  "mode": "paper",
  "spec": {
    "venue": "toss",
    "symbol": "ETF-ROTATION",
    "kind": "rotation",
    "budget": "5000",
    "commission_rate": "0.001",
    "slippage_bps": "5"
  }
}
```

API·엔진·연구 실행기에 동일한 버전을 배포한 뒤 초안을 등록해야 한다. 이전 버전은 새 전략 종류를 해석하지 못한다. DB 스키마 변경은 없다. 미배정 DRAFT도 일봉 준비 대상이므로 저장 후 데이터가 준비되면 시작을 검토할 수 있다. 실제 주문 이후의 코드 롤백은 보유·미체결·원장 대조 없이 수행하지 않는다.

단일 종목 분봉 백테스트 화면은 이 전략에 사용하지 않는다. 7개 종목을 같은 거래일·비용·자금 조건으로 검증해야 하며, 일봉 백테스트가 실시간 체결·장중 손실 중단을 증명하지는 않는다.
