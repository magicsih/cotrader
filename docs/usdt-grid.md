# USDT 보유 반복 그리드

`upbit_usdt`는 같은 업비트 계좌의 USDT 시장을 나타낸다. `upbit`의 KRW 장부와 예산·위험 기준·시세 저장을 분리한다. 두 시장에서 같은 코인의 보유 수량을 중복 배정할 수 없다.

## 시작과 이관

- 신규 준비: USDT 시장 → 실제 계좌 → 보유 코인 전량 반복 그리드 준비. 기본 5단계·0.75%, 첫 매도는 매도 호가보다 한 틱 위다. 호가 단위와 비용 조건으로 구성이 불가능하면 거절한다.
- 원화에서 이관: 기존 전략 중단 → 미체결·미확인 주문 대조 완료 → 원화 전략의 USDT 보유 이관 버튼. 기존 전략 ID·버전·승인 내용을 확인하고 최신 계좌 전량과 원장을 대조한다.
- 모든 계좌·주문 테스트·예산 검사가 끝나야 기존 전략 종료와 새 초안 생성을 한 트랜잭션으로 반영한다. 실제 매도·환전·체결 원장을 만들지 않는다.
- 기존 현금·실현 손익·비용은 보존한다. 이관 보유 평가액과 당시 미실현 손익을 별도로 보존하며, 원화 총 평가에서 사라진 보유분을 손실로 오인하지 않는다. 이 평가액은 사용 가능한 현금이 아니다.
- 새 초안은 수량·현금 0인 미배정 상태다. 사용자가 시작을 확인하면 최신 잔고·가격·주문 가능 여부를 다시 검증한 뒤 편입한다. 오래된 초안은 다시 준비한다.

## 주문과 비용

`execution_policy=maker_only`는 보유 시작 그리드에만 사용한다. 각 단계에 동시에 최대 한 주문을 두며, 체결된 매도대금으로 해당 단계만 재매수한다. 부분 체결·재시작에도 단계의 잔고를 유지한다. 거래소 응답을 확인할 수 없는 주문은 식별자로 대조하며 재전송하지 않는다.

지정가에 `time_in_force=post_only`를 보내며 함께 사용할 수 없는 `smp_type`은 보내지 않는다. 제출 전에 호가와 계좌 내 반대 주문을 대조하고 즉시 체결되는 가격을 보류한다. 거래소에서도 즉시 체결될 주문을 취소한다. 메이커 주문은 실행 중일 때 60초 만료를 적용하지 않는다. 사용자가 중단하거나 위험 한도에 도달하면 취소·보유 유지 정책을 적용한다.

실제 메이커 수수료가 승인한 비용 가정보다 높으면 신규 주문을 거절하고 전략을 중단한다. 기본 비용 가정은 편도 0.25%이며 실제 확정 비용을 체결 원장에 기록한다. 이벤트 참여 여부나 미래 리워드를 수익에 넣지 않는다. 지급 리워드도 별도 계좌 잔액이며 자동으로 전략 예산을 늘리지 않는다.

## 배포

`COTRADER_UPBIT_ENABLED=true`와 기존 계좌 조회 키를 재사용한다. USDT 실거래 서버 허용은 별도 `COTRADER_UPBIT_USDT_LIVE_ENABLED=true`로 설정한다. 공개 예제는 false다. 기본 운용 한도는 `COTRADER_CAPITAL_USDT=500`, 하루 손실 `COTRADER_DAILY_LOSS_USDT=5`, 고점 대비 손실 `COTRADER_DRAWDOWN_USDT=25`다. 이것은 계좌 입금 지시가 아닌 봇의 배정 한도다.

기존 문자열 시장 컬럼을 사용하므로 스키마 변경은 없다. bootstrap이 USDT 계정을 추가한다. USDT 전략을 만든 이후에는 USDT를 모르는 이전 이미지로 되돌리지 않는다. 먼저 엔진을 중단하고 해당 버전의 원장 처리 절차를 검토한다.
