# 공개 코드와 개인 운영 데이터

공개 대상은 애플리케이션 코드, 일반 전략 알고리즘, 가상 데이터 테스트, 의존성 잠금, 일반 배포 예제, 문서다. 개인의 계좌·거래 내역·전략 설정·튜닝 결과·손익·자격증명·실제 인프라 주소는 공개 대상이 아니다.

| 대상 | 보관 위치 |
|---|---|
| 키·세션 서명·DB 연결 | 비공개 자격증명 저장소 또는 런타임 Secret |
| 계좌·주문·체결·전략·연구 결과 | 운영자의 MySQL |
| 실제 도메인·배포 overlay·운영 검증 기록 | Git에서 제외한 `private/` 또는 별도 비공개 운영 저장소 |
| CSV·DB 덤프·백테스트 산출물 | Git에서 제외한 `data/`, `reports/`, `backtests/` 등 |
| 누구나 재현할 예제 | 합성 데이터와 테스트용 값만 |

`.gitignore`는 실수 방지를 돕지만 이미 커밋된 이력을 삭제하지 않는다. 기존 개인 프로젝트를 공개할 때는 코드·문서뿐 아니라 모든 공개될 Git 이력과 작성자 이메일을 점검해야 한다. 개인 이력이 섞였으면 공개할 파일만 새 저장소 이력으로 옮기고 원본은 비공개로 보존한다. `git push --all` 또는 `--mirror`를 사용하지 않는다.

Docker 빌드 컨텍스트는 필요한 코드·잠금 파일만 허용한다. `.git`, `private`, 로컬 환경 파일, 계좌 데이터, 로그는 이미지에 포함하지 않는다. CI는 GitHub 표준 hosted 러너에서 합성 데이터와 임시 DB만 사용하며 운영 키·클러스터 접근 권한을 주입하지 않는다. 외부 PR을 운영 네트워크의 self-hosted 러너에서 실행하지 않는다.

[GitHub 공식 요금 정책](https://docs.github.com/en/billing/concepts/product-billing/github-actions)에 따르면 공개 저장소의 표준 hosted 러너는 무료다. 대형 러너와 저장 공간의 초과 사용은 별도 정책이 적용되므로 모든 사용이 무제한 무료인 것은 아니다.

이 프로젝트는 거래소 시세 데이터의 재배포 권한을 제공하지 않는다. 사용자는 자신의 데이터 이용 권한과 API 약관을 확인해야 한다.
