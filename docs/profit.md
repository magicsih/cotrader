# 마켓별·전체 합산 운용 수익

Telegram `/profit`과 웹 **포트폴리오 → 전체 마켓 운용 수익**에서 확인한다. Telegram은 실거래를, 웹은 선택한 실거래 또는 모의 모드를 집계한다. 두 모드는 합산하지 않는다.

## 집계 범위

- 토스증권 USD, 업비트 KRW, 업비트 USDT의 봇 운용 원장을 각각 표시한다.
- 운용 시작 이후의 누적 손익이다. 보유 자산을 편입한 전략은 편입 당시 평가 기준가부터 계산하며, 편입 전 계좌 손익은 포함하지 않는다.
- 순손익 = 실현손익 − 매수·매도 기록 비용 + 평가손익. 비용 후 실현손익은 실현손익에서 전체 기록 비용을 차감한 소계이며 아직 보유 중인 자산의 매수 비용도 포함한다.
- 종료·인계된 전략은 기존 포트폴리오 스냅샷에 보존된 손익을 사용한다. 인계 평가손익을 다시 더하지 않는다. 누적 비용도 한 번만 차감한다.
- 계좌 전체 손익·입출금·배당·리워드·봇 밖의 보유 자산은 집계 대상이 아니다. 운용 한도가 바뀌어도 순손익에 가상의 수익을 추가하지 않는다.
- 운용 자금의 입출금·재배정 이력을 이용한 수익률 계산은 제공하지 않는다. 운용 한도를 투자 원금으로 간주하지 않는다.

## 원화 합산

전체 합산은 원화를 기본으로 한다. 각 마켓의 누적 손익을 현재 유효한 참고 환율로 환산해 더한다. 보유 기간의 환차손익이나 실제 환전 비용을 포함한 투자 수익은 아니다.

| 통화 | 1단위당 원화 환산 기준 |
|---|---|
| KRW | 1 |
| USD | 토스 `GET /api/v1/exchange-rate`의 `baseCurrency=USD`, `quoteCurrency=KRW`, `midRate` |
| USDT | 업비트 `KRW-USDT` 최우선 매수·매도 호가의 중간가 |

USD와 USDT는 별도 시세를 사용하며 1:1로 취급하지 않는다. 사용한 출처, 조회 시각, 유효 종료 시각을 화면에서 확인할 수 있다.

공식 계약: [토스 OpenAPI 명세](https://openapi.tossinvest.com/openapi-docs/latest/openapi.json)의 환율 방향·매매기준율·유효 시간, [업비트 호가 조회](https://docs.upbit.com/kr/reference/list-orderbooks)의 가격과 응답 시각을 사용한다. 참고 환율과 실제 거래 환율은 다를 수 있다.

## 확인 불가 처리

- 포트폴리오 갱신 후 120초를 넘기거나 보유 시세가 누락된 경우, 미확인 주문이 남은 경우에는 해당 마켓의 집계 상태를 표시하고 전체 합계를 숨긴다.
- 구성 손익 합계와 평가액−운용 한도가 맞지 않으면 원장 대조 필요로 표시한다.
- USD는 제공자가 지정한 유효 시간 안에서만 사용한다. USDT 호가는 응답 시각부터 최대 120초 동안 사용한다. 실패한 조회의 이전 값을 정상 환율로 재사용하지 않는다.
- 일부 마켓이나 필요한 환율이 없다고 0으로 바꾸거나 나머지만 더해 전체 합계로 표시하지 않는다. 이미 확인된 모든 구성 손익이 0인 마켓에는 환율이 필요하지 않다.
- 갱신이 필요한 마켓의 마지막 기록은 시각과 상태를 붙여 표시한다.

## 실행 구조

인증된 `GET /api/profit?mode=live&base_currency=KRW`와 Telegram이 같은 계산 함수를 사용한다. API·Telegram은 저장된 포트폴리오와 환율만 읽는다.

환율 조회는 engine의 기존 브로커와 토큰을 재사용하는 별도 비동기 작업에서 약 30초마다 수행한다. 주문 처리 반복은 환율 응답을 기다리지 않으며 engine 종료 시 조회 작업도 취소한다. `fx:USD:KRW`, `fx:USDT:KRW`에 표시용 값만 저장하고 운용 원장·전략·주문·한도는 변경하지 않는다.
