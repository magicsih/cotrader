# Cotrader

지정가 주문을 한 번에 몰아넣지 않고 **가격 구간에 나눠 거는** 개인용 텔레그램 봇입니다. 토스증권 미국 주식과 업비트 원화·USDT 코인을 지원합니다.

지정가 하나에 전량을 걸면 그 가격에 닿지 않는 한 아무 일도 일어나지 않고, 닿더라도 더 좋은 가격에 체결될 기회를 버립니다. 이 앱은 기준가에서 시작 오프셋과 종료 오프셋 사이를 고른 분할 수로 나눠 여러 개의 지정가 주문을 한 번에 걸어 줍니다.

전략 자동매매, 백테스트, 모의투자, 웹 화면은 없습니다. 주문은 사람이 미리보기를 확인하고 누를 때만 나갑니다.

## 사다리 주문

```
기준가 200,000 · 매도 · 시작 +2.5% · 종료 +10% · 10분할 · 보유 20

  #        가격      수량        금액
  1     205,000         2     410,000
  2     206,700         2     413,400
  3     208,300         2     416,600
  …
 10     220,000         2     440,000

총 수량 20 · 총액 4,249,200 · 평균가 212,460 (기준가 대비 +6.23%)
```

- **기준가**는 현재가, 평균 매수가, 직접 입력 중에서 고릅니다. 현재가는 매도면 최우선 매수호가, 매수면 최우선 매도호가를 씁니다.
- **가격 간격은 등비**입니다. 단계마다 같은 비율만큼 벌어지므로 구간이 넓을수록 기준가에 가까운 쪽이 촘촘해지고, 체결 확률이 높은 구간에 주문이 더 많이 배치됩니다.
- **호가 반올림은 유리한 방향**으로 고정합니다. 매도는 올림, 매수는 내림이라 한 틱도 손해보지 않습니다. 반올림 후 같은 가격이 된 단계는 병합하고 미리보기에 알려 줍니다.
- **매도는 수량을, 매수는 금액을 균등 분배**합니다. 매수에서 금액을 나누면 가격이 낮은 단계일수록 더 많이 사게 되어 평균 단가가 자연히 내려갑니다.
- **나머지는 기준가에 가장 가까운 1단계**에 싣습니다. 체결 확률이 가장 높아 미체결 잔량이 줄어듭니다.

자세한 규칙과 예시는 [사다리 계산](docs/ladder.md)에 있습니다.

## 텔레그램 명령

| 명령 | 내용 |
|---|---|
| `/buy` `/sell` | 분할 주문 만들기 |
| `/balance` | 토스 계좌와 업비트 두 포켓의 잔고 |
| `/orders` | 진행 중인 사다리와 단계별 상태 |
| `/cancel` | 모든 대기 주문 취소 — 보유 자산은 유지 |
| `/transfer` | 업비트 메인 포켓 ↔ 코트레이더 포켓 자산 이동 |
| `/help` | 사용 방법 |

숫자는 화면 안의 숫자판으로 입력합니다. 종목 코드만 답장으로 받습니다. 주문 흐름은 메시지 하나를 계속 고쳐 쓰므로 대화방이 지저분해지지 않습니다.

전송 전 **미리보기**에서 단계별 가격·수량·금액, 합계, 평균가, 가용 자금 대비 여유를 확인합니다. 경고가 하나라도 있으면 전송 버튼이 아예 표시되지 않습니다. 업비트는 가장 가까운 단계와 가장 먼 단계를 거래소의 비체결 테스트로 직접 검증하고, 토스는 미국 시장 세션이 열려 있는지 확인합니다.

## 안전 규칙

실거래에서 지켜야 하는 성질들이며 각각 테스트가 붙어 있습니다.

- 요청을 보내기 **전에** 전송 상태와 시각을 커밋합니다. 프로세스가 중간에 죽어도 전송 시도가 기록에 남습니다.
- 응답을 읽지 못한 주문은 `확인 필요`로 두고 **절대 다시 보내지 않습니다**. 업비트는 우리가 정한 식별자로 조회해 복구하고, 토스는 조회 응답에 식별자가 없으므로 사용자가 증권사 앱에서 대조합니다.
- 같은 시장에 확인되지 않은 주문이 하나라도 있으면 그 시장의 새 주문을 전부 막습니다.
- 취소 접수는 취소 완료가 아닙니다. 거래소가 확인해 줄 때까지 `취소 확인 중`으로 둡니다.
- 체결 금액은 거래소가 보고한 실제 체결 내역만 씁니다. 지정가 × 수량으로 추정하지 않습니다.
- 출금 경로는 코드에 존재하지 않습니다. 허용 엔드포인트 목록에 없어 어떤 경로로도 도달할 수 없습니다.
- 같은 계좌에 두 인스턴스가 뜨면 두 번째는 기동을 거부합니다.

## 실행

Go 1.26과 Docker가 필요합니다.

```bash
bash scripts/local-db.sh start
cp .env.example .env          # 값을 채웁니다
go run ./cmd/cotrader
```

기본값은 모든 시장의 주문이 꺼져 있습니다. 이 상태에서도 잔고 조회, 미리보기, 주문 대조는 동작합니다. 실제 주문은 시장별 스위치를 켜야 나갑니다. 연결 방법은 [연결 설정](docs/connections.md)을 참고하세요.

gofmt -l .
